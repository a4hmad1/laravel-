## 📌 ڤیو مۆدێل بە کوردی چییە؟

کاتێک پەڕەیەکی داشبۆرد دەکەیتەوە، کۆنتڕۆڵەر ناچار دەبێت ١٠ جۆر زانیاری بهێنێت (کۆی کڕینەکان، دوایین بەکارهێنەران، خشتەی مانگانە، باڵانس). ئەگەر هەموو ئەم داتایانە لە کۆنتڕۆڵەر بنووسیت، کۆنتڕۆڵەر دەبێتە دێوەزمە!  
کڵاسی `DashboardViewModel` هەموو ئەم داتایانە کۆدەکاتەوە و ئامادەی دەکات، و کۆنتڕۆڵەر تەنها یەک دێڕ دەبێت:  
`return view('dashboard', new DashboardViewModel());`
