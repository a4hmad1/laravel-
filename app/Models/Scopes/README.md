# 🔍 Model Scopes (`app/Models/Scopes`)

> **ئاستی فێربوون**: 🔴 Senior (هەنگاوی ٢٤)

## 📌 ئەم فۆڵدەرە چییە؟
کڵاسەکانی Scope بەکاردێن بۆ دانانی فلتەری هەمیشەیی یان دووبارە بەکارهاتوو لەسەر کوێرییەکان. بۆ نموونە (Global Scope) کە بە شێوەیەکی ئۆتۆماتیکی تەنها بەکارهێنەرە چالاکەکان دەهێنێت بەبێ ئەوەی هەموو جارێک بنووسیت `where('status', 'active')`.
