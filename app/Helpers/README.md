# 🛠️ فانکشنە یاریدەدەرەکان — Helpers (`app/Helpers`)

> **ئاستی پێویست:** ئاستی ناوەند (Mid-Level Developer)  
> **ئامانجی سەرەکی:** کۆکردنەوەی ئەو فانکشنە کورتبڕانەی لە زۆربەی پڕۆژەکەدا بەکاریان دەهێنیت.

---

## 📌 هێڵپەر بە کوردی چییە؟

ئەو فانکشنە کورتبڕ و سووکەڵانەیە کە پێویستت پێیان دەبێت لە ناو ڕووکاری وێب، کۆنتڕۆڵەر یان مۆدێل، وەک:
* گۆڕینی ژمارە بۆ نرخی دراو (`format_money(25000)` ──► `25,000 د.ع`).
* کورتبڕکردنی تێکستی درێژ بە شێوەیەکی جوان.
* گۆڕینی بەرواری زایینی بۆ کوردی.
