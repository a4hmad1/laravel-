# 🎭 Custom Casts (`app/Casts`)

> **ئاستی فێربوون**: 🔴 Senior (هەنگاوی ٢٤)

## 📌 ئەم فۆڵدەرە چییە؟
کاتێک داتایەک لە داتابەیس بە شێوازێک پاشەکەوت دەکرێت (بۆ نموونە ناونیشان بە JSON)، Custom Cast ڕێگەت پێدەدات بە ئۆتۆماتیکی لە کاتی هێنان بیکاتە ئۆبجێکتێکی تایبەت و لە کاتی سەیڤکردن بیکاتەوە بە دەقی داتابەیس.
