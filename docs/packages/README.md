## ١. ئاسایش و چوونەژوورەوە (Auth & Security)

### 🔐 1. Laravel Sanctum
* **کاری چییە؟** دروستکردنی تۆکنی خێرای API بۆ ئەپڵیکەیشنی مۆبایل و پاراستنی ماڵپەڕە تاک پەڕەکان (SPAs وەک Vue و React) لە ڕێگەی Cookies و Sessions.
* **سوودەکەی:** زۆر سووکەڵە و ئاسانە بەراورد بە سیستەمی ئاڵۆزی OAuth2.
* **فەرمانی دابەزاندن:** `php artisan install:api`

### 🛡️ 2. Laravel Passport
* **کاری چییە؟** سێرڤەری تەواوی OAuth2 بۆ ئەو پڕۆژانەی دەبێت کلیلی نهێنی (Client Secret) بدەنە کۆمپانیا و بانکی دەرەکی بۆ بەستنەوەی سیستەمەکانیان.
* **سوودەکەی:** ستانداردی باڵای جیهانی بۆ پڕۆژە گەورەکانی وەک فەیسبووک و گووگڵ کە API دەدەنە دەرەوە.

### 🚀 3. Laravel Breeze & Jetstream
* **Breeze:** دەستپێکێکی زۆر سادە و پاک بۆ لاپەڕەکانی Login, Register, Forgot Password بە تەکنەلۆژیای Blade یان Vue/React.
* **Jetstream:** سیستەمی پێشکەوتووی چوونەژوورەوە کە لەخۆگری: چوونەژوورەوەی دوو قۆناغی (2FA)، کۆنتڕۆڵی سێشنەکان، و بەڕێوەبردنی تیمەکانە (Teams).

## ٢. خێرایی، کاتی ڕاستەوخۆ و چاودێری (Performance & Real-Time)

### ⚡ 4. Laravel Reverb
* **کاری چییە؟** بزوێنەری فەرمی و زۆر خێرای پەخشی ڕاستەوخۆ (WebSockets) کە لەناو خودی لارافێڵدا دروستکراوە.
* **سوودەکەی:** لە بری ئەوەی مانگانە پارە بە Pusher بدەیت، Reverb دەتوانێت ملیۆنان پەیوەندی لە چرکەیەکدا لەسەر سێرڤەری خۆت بەخۆڕایی بەڕێوەببات!

### 📊 5. Laravel Horizon
* **کاری چییە؟** داشبۆردێکی زۆر پێشکەوتوو بۆ چاودێریکردنی ئەرکە پاشبنەماییەکان (Queues بە Redis).
* **سوودەکەی:** پیشانی دەدات لە چرکەیەکدا چەند ئەرک ئەنجام دەدرێن، کام ئەرک شکستی هێناوە، و چەند کاتی پێچووە.

### 🩺 6. Laravel Pulse
* **کاری چییە؟** چاودێری تەندروستی سێرڤەر (Server Health Monitoring).
* **سوودەکەی:** بە گرافیک ڕێژەی بارگرانی CPU، بەکارهێنانی RAM، هێواشترین کوێرییەکانی داتابەیس، و هێواشترین ڕێڕەوەکانی وێب پیشان دەدات.

### 🔭 7. Laravel Telescope
* **کاری چییە؟** هاوڕێی هەرە نزیکی پڕۆگرامەر لە کاتی کۆدنووسین (Debugging).
* **سوودەکەی:** هەموو داواکارییەک، هەموو ئیمەیڵێک کە نێردراوە، هەموو کوێرییەکی SQL، و هەموو هەڵەیەک ڕاستەوخۆ لە ناو شاشەیەکدا تۆمار دەکات بەبێ پێویستی سەیرکردنی لۆگەکان.

---

## ٣. فرۆشتن و دەروازەی پارەدان (Billing)

### 💳 8. Laravel Cashier (Stripe / Paddle)
* **کاری چییە؟** بەستنەوەی کڕینی بەشداریکردنی مانگانە (Subscription) لە ڕێگەی Stripe یان Paddle.
* **سوودەکەی:** هەموو پسوڵەکان، هەڵوەشاندنەوەی بەشداریکردن، و پشکنینی کارتی بانکی بە شێوەیەکی ئۆتۆماتیک ڕێکدەخات.

---

## ٤. گەڕان و سێرچ (Search)

### 🔍 9. Laravel Scout
* **کاری چییە؟** گەڕانی زۆر خێرا و مۆدێرن (Full-Text Search) لە ناو مۆدێلەکاندا بە بەستنەوەیان بە بزوێنەرەکانی وەک **Meilisearch** یان **Algolia**.
* **سوودەکەی:** کاتێک قوتابی پیتی یەکەمی کۆرسێک دەنووسێت، لە کەمتر لە ٠.٠١ چرکەدا هەموو ئەنجامەکان پیشان دەدات و هەڵەی پیتیش چاک دەکاتەوە!

---

## ٥. تۆڕە کۆمەڵایەتییەکان (Socialite)

### 🌐 10. Laravel Socialite
* **کاری چییە؟** چوونەژوورەوە بە یەک کلیک لە ڕێگەی (Google, GitHub, Facebook, Apple).
* **سوودەکەی:** بە ٥ دێڕ کۆد کڕیار دەتوانێت بە ئەژماری گووگڵ بچێتە ناو پڕۆژەکەتەوە بەبێ پێویستی پڕکردنەوەی فۆڕمی وشەی نهێنی.

---

## ٦. ئامرازەکانی پەرەپێدان (Developer Tools)

### 🎨 11. Laravel Pint
* **کاری چییە؟** ڕێکخەر و خاوێنکەرەوەی خۆکاری شێوازی نووسینی کۆدی PHP (Code Formatter).
* **سوودەکەی:** بە یەک فەرمانی `vendor/bin/pint`، هەموو فایلەکانی پڕۆژەکەت بە ستانداردی پاک و جیهانی ڕێکدەخات.

### 🚢 12. Laravel Sail
* **کاری چییە؟** ژینگەی Docker ئامادەکراو بۆ لارافێڵ. ڕێگە دەدات بەبێ دابەزاندنی MySQL یان Redis لەسەر کۆمپیوتەرەکەت، هەمووی بە Container لە چەند چرکەیەکدا ئامادە بێت.

### 🎭 13. Laravel Dusk
* **کاری چییە؟** تاقیکردنەوەی ڕاستەقینە لە وێبگەڕدا (Browser Automation Testing). وێبگەڕی Chrome دەکاتەوە، کلیک دەکات، و وێنەی شاشە دەگرێت بۆ دڵنیابوونەوە لەوەی هیچ دوگمەیەک تێک نەچووە.
