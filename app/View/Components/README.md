# 🧩 پێکهاتەکانی دیزاین — View Components (`app/View/Components`)

> **ئاستی پێویست:** ئاستی ناوەند (Mid-Level Developer - هەنگاوی ١٥)  
> **ئامانجی سەرەکی:** دروستکردنی پارچە دووبارەبووەکانی دیزاین لەگەڵ لۆجیکی تایبەت بەخۆیان لە Blade.

---

## 📌 کۆمپۆنێنت بە کوردی چییە؟

کۆمپۆنێنت وەک **خشتی ئامادەکراوی بیناسازی** وایە!  
لە بری ئەوەی کۆدی دوگمەیەک (Button) یان کاردێک (Card) لە ٥٠ لاپەڕەدا کۆپی بکەیت و سبەی ئەگەر ڕەنگەکەی گۆڕا ناچار بیت ٥٠ فایل بکەیتەوە:  
یەک کۆمپۆنێنت لەم فۆڵدەرە دروست دەکەیت و تەنها دەنوسیت:  
`<x-alert type="danger" message="وشەی نهێنی هەڵەیە!" />`

کڵاسەکەی ناو ئەم فۆڵدەرە لۆجیکەکەی کۆنتڕۆڵ دەکات، و فایلی Bladeـەکەی دیزاینەکەی پیشان دەدات.
