# 📤 Responses (`app/Http/Responses`)

> **ئاستی فێربوون**: 🔴 Senior (تەلارسازی پێشکەوتوو)

## 📌 ئەم فۆڵدەرە چییە؟
کڵاسەکانی Responsable شێوازی وەڵامدانەوەی پڕۆژەکە کۆنتڕۆڵ دەکەن. یارمەتیت دەدات شێوازی دەرچوونی API یان پەڕەکان لە تەواوی پڕۆژەکەدا بە یەک ڕێسای پێوانەیی بڕوات (Standard Response Structure).
