# 🗄️ کۆگا و لۆگەکان — Storage (`storage`)

> **ئاستی پێویست:** ئاستی سەرەتایی بۆ ناوەند (Junior to Mid-Level)  
> **ئامانجی سەرەکی:** شوێنی هەڵگرتنی فایلەکانی پڕۆژە لە کاتی کارکردنی سێرڤەردا.

---

## 📌 کۆگا بە کوردی چییە؟

کۆگا شوێنی ئەمانەیە:
1. **`app/public/`:** وێنەی کەسی، فایلی کۆرس و بەڵگەنامەی بارکراوی بەکارهێنەران.
2. **`framework/`:** ئەو شتانەی لارافێڵ خۆی دروستیان دەکات وەک کاشی خێرا و لاپەڕە کۆمپایڵکراوەکان.
3. **`logs/`:** فایلی گرنگی `laravel.log`؛ ئەگەر پڕۆژەکەت هەر هەڵەیەکی کرد، یەکسەر لێرە تۆمار دەبێت تا بزانیت کێشەکە چی بووە.

---

## 🛠️ فەرمانی بەستنەوەی کۆگا بە وێبگەڕ:

```bash
php artisan storage:link
```
