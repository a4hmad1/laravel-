# ⚙️ ڕێکخستنە سەرەکییەکان — Configuration (`config`)

> **ئاستی پێویست:** ئاستی سەرەتایی بۆ ناوەند (Junior to Mid-Level)  
> **ئامانجی سەرەکی:** کۆکردنەوەی هەموو ڕێکخستنەکانی سێرڤەر و پەیوەندییە دەرەکییەکان لە یەک شوێنی سەلامەتدا.

---

## 📌 ڕێکخستن بە کوردی چییە؟

هەموو سێرڤەر و پڕۆژەیەک پێویستی بە ناساندنی سنوورەکانە؛ وەک:
* کام بنکەدراوە بەکاردێت (MySQL, PostgreSQL, SQLite)؟ لە `database.php` دانراوە.
* ماوەی مانەوەی بەکارهێنەر لە سیستم (Session) چەند خولەکە؟ لە `session.php` دانراوە.
* پڕۆژەکە چەند زمانی لەخۆ گرتووە؟ لە `app.php` دانراوە.

ڕێسای زێڕین ئەوەیە: **هەرگیز وشەی نهێنی ڕاستەوخۆ لەم فۆڵدەرە نانووسرێت!** بەڵکو هەمیشە لە ڕێگەی `env()` لە ناو فایلی شاراوەی `.env` دەخوێندرێتەوە تا لە کاتی بردنە سەر گیت‌هەب زانیارییەکان دزە نەکەن.
