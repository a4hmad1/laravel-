## 📌 جۆب میدڵوێر بە کوردی چییە؟

ئەگەر جۆبێک بنێریت بۆ دەروازەیەک (وەک OpenAI یان کورتەنامە) کە تەنها ڕێگە دەدات لە خولەکێکدا ٦٠ داواکاری بنێریت؛ ئەگەر تۆ یەک ملیۆن جۆب پێکەوە ئیش پێبکەیت، هەژمارەکەت دەسڕدرێتەوە!  
کڵاسەکانی ئەم فۆڵدەرە لە بەردەرگای جۆبەکان دەوەستن و ڕێژەی خێراییان لەسەرخۆ دەکەنەوە (Rate Limiting).
