# ⚡ کۆدی فرۆنتێند — JavaScript & Vite (`resources/js`)

> **ئاستی پێویست:** ئاستی ناوەند (Mid-Level Developer)  
> **ئامانجی سەرەکی:** دروستکردنی کارلێکی خێرا و مۆدێرن لە ڕێگەی کتێبخانەکانی JavaScript وەک Vue، React، یان Alpine.js.

---

## 📌 جاڤاسکریپتی پڕۆژەکە بە کوردی چییە؟

ئەم فۆڵدەرە ماڵی تەواوی کۆدەکانی فرۆنتێندە. پێش ئەوەی کۆدەکان بگەنە وێبگەڕ، لە ڕێگەی بزوێنەری خێرای **Vite** کۆمپایڵ دەکرێن و دەپەستێورێن تا ماڵپەڕەکە بە خێرایی با دەستبەجێ بکرێتەوە.  
تەلارسازی ئەم فۆڵدەرە دابەشکراوە بەسەر:
* `components/`: کۆمپۆنێنتەکانی UI (وەک مۆدال، لیستی دابەزێنەر).
* `composables/`: فانکشنە هاوبەشەکانی فرۆنتێند.
* `services/`: پەیوەندی کردن بە سێرڤەر بە بەکارهێنانی Axios.
