# 🎨 لاپەڕەکانی ڕووکار — Blade Views (`resources/views`)

> **ئاستی پێویست:** ئاستی سەرەتایی (Junior Developer - هەنگاوی ٣)  
> **ئامانجی سەرەکی:** داڕشتن و ڕێکخستنی شاشەی بینراوی ماڵپەڕ بە زمانی پێشکەوتووی Blade.

---

## 📌 بلەید (Blade) بە کوردی چییە؟

بلەید مۆتۆڕی ڕووکاری لارافێڵە کە ژیری خستووەتە ناو کۆدی ئاسایی HTML.  
بە بەکارهێنانی فرمانی وەک `@if`, `@foreach`, `@auth` دەتوانیت دیزاینەکەت زیرەک بکەیت (بۆ نموونە: تەنها کاتێک دوگمەی کڕین پیشان بدە کە بەکارهێنەر چوو بێتە ژوورەوە).

---

## 📂 دابەشبوونی فۆڵدەرەکانی ناو `views`:
* **`layouts/`:** نەخشەی سەرەکی پەڕەکان (وەک هێدەر و فوتەری هاوبەش).
* **`partials/`:** پارچە دووبارەبووەکانی پەڕە وەک ناوڤبار و سایدبار.
* **`components/`:** دوگمە و کاردە بچووکەکان.
* **`emails/`:** شێوازی ئەو ئیمەیڵانەی دەنێردرێن.
* **`errors/`:** پەڕەی هەڵەکانی وەک 404 و 500.
